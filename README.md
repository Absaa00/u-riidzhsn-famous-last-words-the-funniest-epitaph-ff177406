# Famous Last Words: The Funniest Epitaph

[![make.fun](https://make.fun/badge.svg)](https://make.fun/competitions/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406)

A deterministic Python program (standard library only, no network) that
writes a single one-line tombstone epitaph of famous last words to
`/output/entry.txt` — at most 150 characters, one line, one joke, one
twist.

## The entry

> My last words were 'hold my beer.' This stone is the receipt.

The speaker's actual last words are the reckless dare "hold my beer",
and the twist lands in the second sentence: the tombstone itself turns
out to be the receipt for that dare.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (61 characters, one line). Two runs produce
byte-identical output.
